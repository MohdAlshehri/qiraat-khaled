# qiraat-khaled
## التثبيت كتطبيق (PWA)
- السكربت: `tools/pwa.py` (يُشغّل من جذر المستودع: `python3 tools/pwa.py`).
- يولّد أيقونات `assets/`، و `manifest.webmanifest`، و `sw.js`، ووسوم التثبيت بين `<!-- PWA:START -->` و `<!-- PWA:END -->` في الصفحات.
- الاسم والاسم المختصر والألوان والشعار في أعلى السكربت. أعد تشغيله عند تغيّرها. التشغيل مرتين لا يغيّر شيئاً.
